# Astrolabe

**The Git client for the parallel-agent era.**
Everyone helps you launch the ships. Astrolabe brings them home.

You run several AI coding agents at once. Every tool helps you *launch* those tasks —
nobody helps you *land* them. Astrolabe owns the landing half: merging, resolving,
and knowing who wrote which side.

### Fleet
Every AI task gets its own branch and git worktree — a *berth* — with live status.
One board shows what is running, what is blocked, and what is ready to land.

### Author Lens
Per-hunk conflict attribution. Each side of a conflict shows who wrote it: author,
commit subject, short hash, relative time. Task-aware via `Co-Authored-By` trailers,
so it can tell an agent's work from your own.
